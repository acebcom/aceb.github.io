What it is

ACEB.com is an online shop for digital gift cards paid with cryptocurrency. Its public Model Context Protocol server gives an AI assistant the tools to search the catalog, read product details, quote prices, build a cart and open a checkout.

https://api.aceb.com/mcp
  • Transport: Streamable HTTP
  • Authentication: none
  • Price: free

Connect

Claude

Settings → Connectors → Add custom connector, then enter the endpoint URL.

Claude Code

claude mcp add --transport http aceb https://api.aceb.com/mcp

ChatGPT

Turn on developer mode in the connector settings, then create a connector with the endpoint URL and no authentication.

Cursor

Add the server to ~/.cursor/mcp.json:

{ "mcpServers": { "aceb": { "url": "https://api.aceb.com/mcp" } } }

VS Code

Add the server to .vscode/mcp.json:

{ "servers": { "aceb": { "type": "http", "url": "https://api.aceb.com/mcp" } } }

Then ask in plain words: "Find a 50 EUR Steam gift card for Germany and add it to a cart."

Tools

ToolWhat it does
search_productsSearch in-stock gift cards by text, category and country.
get_productDescription, terms, how to redeem, FAQ and face values of one gift card.
quote_priceWhat the shopper pays for a card of a given face value.
get_cartRead a cart.
create_cartAdd items to a cart and get a shareable cart link.
update_cart_itemChange the quantity or face value of a cart line.
remove_cart_itemRemove a cart line.
list_payment_methodsPayment methods with the coins, networks and wallet apps each accepts.
create_crypto_checkoutOpen a hosted crypto payment session and return its link.
get_order_statusStatus of an order created through these tools.
get_site_contentFAQ, terms, privacy, returns and other information pages, in 12 languages.

Safety

  • The human always pays. No tool moves money. A checkout returns a link to a hosted payment page.
  • Codes stay out of the chat. Gift card codes are delivered to the order email and are never returned by a tool.
  • Explicit intent. Carts and checkouts are created only when the user asks for them.
  • Any payment method. The cart link opens on aceb.com, where every payment method is available.
